# Contributing

Contributions are welcome. See `contributing.qmd` for the guide's own text, which covers how to propose and write a new worked example. Key requirements for a new example:

- A pinned `environment.yml`.
- A verbatim prompt with provenance (model and date).
- A validation section.
- Publicly available sample data with its licence noted, never committed to the repository.
- No raw image data committed.

Style: British English, plain language (no assumed programming knowledge), and a visible `TODO` for anything unverified.
